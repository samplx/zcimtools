# How to Contribute

## Thank You

Thank you for your interest in zcimtools, ZCim, the site z80cim.org and the software that helps keep it alive.

## Guidelines

- Please see the [existing issues](https://github.com/samplx/zcimtools/issues) or add a new one.

## Contribution Types

* Reporting Issues
* Software Components

## Reporting Issues

Please help me make the site better by reporting problems you find.
Any additional information that allows me to reproduce the problem
is especially helpful. Too much is better than too little.

## Software Components

The standard procedure is this:

1. Fork the repository and clone the fork.
2. Make the changes required to correct the problem in the forked repository.
3. Push your changes to your forked repository.
4. Make a pull request with a description of the changes and the associated issue.
5. Work with me to resolve any code review issues with the pull request.
6. Approved pull request is merged.
